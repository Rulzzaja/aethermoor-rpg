# Aethermoor: Penjaga Cahaya (Action RPG 3D)

Proyek Game Action RPG 3D berbasis Web (Three.js, TypeScript, dan Vite).

## Fitur Utama
- **3 Kelas Karakter & Kustomisasi 3D**: Ksatria, Penyihir, dan Pemanah.
- **Dunia Terbuka (Overworld) & Dungeon Katakombe**: 5 wilayah eksplorasi dengan tingkat kesulitan musuh berjenjang (Lv.1 - Lv.10).
- **Sistem Combat & VFX Skill 3D**: Kombo serangan dasar, 3 skill aktif per kelas, dodge roll, dan lock-on target.
- **Sistem RPG Lengkap**: Quest berurutan, Level Up, Gacha Senjata Pusaka, Tempa/Upgrade Senjata di Pandai Besi, dan Toko Ramuan.

## Cara Menjalankan Proyek
1. Pastikan Node.js sudah terinstal.
2. Jalankan perintah berikut di terminal:
   ```bash
   npm install
   npm run dev
   ```
3. Buka link localhost yang muncul di browser.
